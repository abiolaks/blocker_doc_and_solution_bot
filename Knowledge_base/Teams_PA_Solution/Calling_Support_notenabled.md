# Calling Support Not Enabled; Bot was not supporting calls

## Problem
The bot could not support meetings or calling immediately.

## Root Cause
Normal Teams bots do not automatically support calls and meetings.

## Solution
Enabled the Microsoft Teams channel and turned on Calling support in Azure Bot configuration.

## Environment
- Azure Bot Service
- Microsoft Teams

## Tags
Azure Bot, Teams Channel, Calling Support

- Project: Teams PA Solution
